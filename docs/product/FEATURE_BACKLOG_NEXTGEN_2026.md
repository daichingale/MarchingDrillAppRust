# DrillForge NextGen Feature Backlog — 2026-10-23
**種類:** 提案・優先順位・完了条件 / **関係:** [Master Plan v2](../MASTER_PLAN_NEXTGEN_2026.md) / [UX Spec](INTERACTION_SPEC_NEXTGEN_2026.md)

この一覧は「これだけあれば完璧」と主張するものではない。**現場実証で優先順位と機能範囲を継続的に更新するためのバックログ**。既存の実装状況を未検証のまま「完了」としない。

## 凡例・採否基準

- **優先度:** `S0` データ破損/安全性、`S1` 日常制作の基本、`S2` 練習/演出差別化、`S3` 研究・高度機能。
- **状態:** `確認` 現行実装の検証、`改善` 既存機能の使いやすさ/精度改善、`提案` 未採用の新案、`外部` 実機・運用条件に依存。
- **Done:** 型/保存/Undo/同期/パフォーマンス/日本語英語/回帰/実機操作の必要部分が揃い、証拠リンクがある。ソースが存在するだけではDoneにしない。
- **時間見積:** この表では実装日数を推測しない。依存関係と品質ゲートで順序を決める。

## 実際の着手順（最初の5本の小さなPR）

1. **F-001/F-006:** 修正・根拠の更新のみ。CI全緑、現況との齟齬を明示。
2. **D-011/D-012:** 選択/座標入力/ドラッグの受入試験と修正。机上で作り直さずUX実測。
3. **M-025/M-034:** ルートとカウントの時刻一致。PR #62 の実機確認と必要修正。
4. **P-075/P-076:** CSV/XLSXの差分プレビュー。古いシートを安全に移行。
5. **R-063/R-065/R-064:** 今日の練習範囲 → A4 → 個人ビュー の一本化。
