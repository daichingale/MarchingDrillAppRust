# DrillForge

Pyware 3D級のマーチングドリル制作環境を目指す、Rust製デスクトップアプリです。現在は高速な2D編集・セット間アニメーション・安定したドキュメントモデルを備えたMVPです。

## 起動

```powershell
cargo run --release -p drill-app
```

演者をクリック、または空白から範囲ドラッグして選択できます。`Ctrl/Cmd`を押しながら選ぶと選択を追加でき、まとめて移動・回転・拡大縮小・等間隔配置できます。`Ctrl/Cmd+Z`と`Ctrl/Cmd+Y`でUndo/Redo、再生ボタンでセット間の動きを確認できます。LIVE CLINICは衝突候補と過大な歩幅を常時検査します。

`Ctrl/Cmd+S`で保存できます。既存ファイルの保存前には `.backup.drill.json`、編集中は30秒ごとに `.autosave.drill.json` が作られます。

## アーキテクチャ

- `drill-core`: UIに依存しない譜面、演者、セット、補間、保存形式、編集コマンド
- `drill-app`: eguiによる即時モードUI、wgpuによるGPU描画
- 演者座標はセットごとの密な `Vec<Point>`。再生時に同じ出力バッファを再利用し、フレームごとのヒープ確保を避けます。
- 永続形式はバージョン付きJSON。将来は圧縮コンテナへ移行してもコアAPIを維持できます。

## 実装済み

- 直線・斜線・円弧・円・ブロック・螺旋・ベジェのフォーメーション生成、スナップ、範囲選択
- 整列・等間隔分配・左右/前後反転・回転・拡大縮小などの編集ツール
- 可変BPMのテンポマップ（カウント⇄秒⇄小節変換）と、それに連動した再生
- マーチング座標の読み上げ（「サイド1 45ヤードラインの内側に2歩」等）とコンティニュイティ表示
- 遷移解析（衝突候補・過大歩幅・最大歩幅・総移動距離）
- セット間の担当ドット自動割り当て（隊形は保ったまま総移動距離を最小化）
- 3Dスタジアム表示（観客席／プレスボックス／真上プリセット、ドラッグ回転・ホイールズーム）
- 参照音源との同期モデル（オフセット・クリック/ダウンビート）とカウントシート（リハーサル記号付き）
- 書き出し: 座標CSV、フィールド図SVG、座標シート/ドリルブックHTML（ブラウザ印刷でPDF化）、
  カウントシート/コンティニュイティTXT
